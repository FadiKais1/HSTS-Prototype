## 2. Build

```powershell
mvn clean package 2>&1 | Out-File -Encoding utf8 mvn_output.txt
```

Produces `target\G7_Server.jar` and `target\G7_Client.jar` after running all
tests. **A red build produces no jars.**

> Stop the server first. A running server holds `G7_Server.jar` open and the
> clean step fails on it.

Use `mvn clean test` when you only want to check nothing broke.

## 3. Load the database

Three commands, one at a time. Replace `root` with your MySQL user.

```powershell
mysql -u root -p -e "DROP DATABASE IF EXISTS hsts_prototype; CREATE DATABASE hsts_prototype;"
```

```powershell
cmd /c "mysql -u root -p hsts_prototype < database\init.sql"
```

```powershell
cmd /c "mysql -u root -p hsts_prototype < database\seed_demo_data.sql"
```

> PowerShell does not support `<` for input redirection, which is why these go
> through `cmd /c`.

Expect this verification table:

| courses | 11 |
| users | 53 |

| exams | 20 |

Counts exceed the seed's own totals because `init.sql` adds a legacy subject,
course, six questions and four development accounts of its own.

The data is generated by `tools/build_seed.py`. **Edit that script, not the
SQL**, then re-run `python tools\build_seed.py`.

## 4. Start

**Server** — one window, kept open. It prints connections and the full cause of
any failure.

```powershell
$env:HSTS_DB_USER = "root"
$env:HSTS_DB_PASSWORD = "your-mysql-password"
java -jar target\G7_Server.jar
```

Listens on port **5555**. `HSTS_DB_URL` overrides the connection string.

**Client** — a separate window per user signed in at once.

```powershell
java -jar target\G7_Client.jar
```

The connection screen appears first (NFR 15).

### Course Bot provider

**Offline is the default** and needs no key. It answers by matching the question
against the teacher's sources. Reproducible, so preferred for recording results.

**Gemini** — set these in the **server** window before starting it:

```powershell
$env:HSTS_BOT_PROVIDER = "GEMINI"
$env:HSTS_GEMINI_API_KEY = "AIza..."
$env:HSTS_GEMINI_MODEL = "gemini-3.5-flash"
```

Keys come from `aistudio.google.com/apikey` and begin `AIza`. **Never commit a
key or include one in the submission.**

**Fallback if it fails mid-demo.** Stop the server, then:

```powershell
Remove-Item Env:HSTS_BOT_PROVIDER
java -jar target\G7_Server.jar
```

Rehearse this once.

## 7. Troubleshooting

| Symptom | Cause |
|---|---|
| `Unable to access jarfile` | `mvn clean test` was run instead of `package`, or the build failed |
| `Failed to delete G7_Server.jar` | The server is running; stop it first |
| `Unknown database 'hsts'` | The database is `hsts_prototype` |
| `The '<' operator is reserved` | Use `cmd /c "... < file.sql"` |
| `git am` refuses to run | A previous one is stuck: `git am --abort` |
| Anything fails in the app | The **server window** prints the full cause chain |
| A student cannot start an exam | She has already attempted that execution |
| The bot declines a fair question | The material does not cover it; add a source as the teacher |
