# HSTS — Demo Data and Testing Guide

Which account to use for each scenario, and what the data already contains.

Load with:

```powershell
mysql -u root -p -e "DROP DATABASE IF EXISTS hsts_prototype; CREATE DATABASE hsts_prototype;"
cmd /c "mysql -u root -p hsts_prototype < database\init.sql"
cmd /c "mysql -u root -p hsts_prototype < database\seed_demo_data.sql"
```

The data is generated by `tools/build_seed.py`. **Edit that script, not the SQL**,
then re-run it to regenerate the seed file.

## 3. Scenario guide

### Question bank — create, edit, delete, version (req 33, 34)

**Rania Haddad** → Question Bank → subject **Mathematics** → course **MATH-10A**.

Identifiers read `01001`, `01002` — course number then question number.
Create one and it becomes `01017`. Edit and **Save Versioned Update** to raise
its version; edit and **Save as New Question** to leave the original alone.
**Delete Question** hides it from the bank while exams keep it.

### A teacher across several subjects (req 15)

**Rania Haddad** teaches Maths *and* Physics. The subject picker narrows the

### Two teachers, one course — live updates (req 15, NFR 18)

## 4. Regenerating

```powershell
python tools\build_seed.py
```

Edit the lists at the top of that script to add subjects, courses, staff,
students, questions or exams. Identifiers, password hashes, checksums, scores
and statistics are all derived, so they stay consistent.
